# 메시지 개봉과 캐릭터 규칙

> Source: Deep Interview, 2026-11-16
> 2026-11-20 개정 (#38): 숨김 랜덤을 없애고 선택기의 랜덤 선택 버튼으로 바꿈, 선택 확인 창, 이로치 2%, 공개 전 이로치 볼 반짝임, 공개 후 트리에 포켓몬 표시

## Key Points (확정)

### 개봉 시점
- 메시지가 도착하면 **트리에 장식이 즉시 달린다.** 장식 개수도 바로 보인다.
- **메시지 내용과 캐릭터는 12/25에 공개된다.**

### 캐릭터 지급 방식
- 랜덤 지급이 아니라 **메시지 작성자가 포켓몬을 골라서 보낸다.** 롤링페이퍼의 "선물" 성격을 살리는 방식이다.
- 포켓몬 선택 화면에 **"랜덤" 버튼**을 둔다. 전체 포켓몬 중 한 마리를 골라 확인 창으로 보여 준다. 작성자가 확인하고 고르므로 직접 고른 것과 같게 기록한다. (2026-11-20 변경. 이전: 작성 화면의 "랜덤으로 보내기" 체크박스로 서버가 고르고 작성자에게도 숨김)
- 포켓몬을 고를 때마다 확인 창을 띄우고, **2% 확률로 이로치**가 당첨된다 (POL-CHR-11, 12).
- 작성자가 직접 고를 때는 중복을 허용한다. 여러 작성자가 같은 포켓몬을 보낼 수 있다.

### 수집 범위와 도감
- 대상은 **전체 포켓몬 + 리전폼**(알로라, 가라르, 히스이, 팔데아)이다. 메가진화, 거다이맥스 등 나머지 폼은 제외한다.
- **전체 도감 채우기(수집률, 빈칸)는 없앤다.** 받은 포켓몬만 모아서 보여 준다.
- 기존 후보였던 희귀도, 도감 완성 보상, 수집률 표시는 이 결정으로 제외한다.

## 대체 캐릭터 팩에 미치는 영향 (주의)

포켓몬이 1,000종이 넘고 작성자가 직접 고르므로, 1:1 대체 팩은 혼자 만들 수 없다. 그래서 삭제 요청을 받으면 다음처럼 전환하는 방안을 제안한다.
- 포켓몬 선택기를 끄고, 소수의 범용 오너먼트(예: 10~20종) 중에서 고르게 한다
- 기존 메시지의 포켓몬은 번호를 기준으로 범용 오너먼트에 대응시켜 표시한다
- 메시지 내용은 그대로 유지한다
