# MVP 범위 (12/1 출시)

> Source: Deep Interview, 2026-11-16

## 추가로 확정된 게임 규칙

- **12/25 이전 장식 표시:** 작성자 닉네임만 보인다. 장식은 선물상자나 오너먼트 모양이며, 포켓몬과 메시지 내용은 비밀이다. 트리 링크를 가진 방문자에게도 같은 화면이 보인다.
- **12/25 이후 도착한 메시지:** 도착 즉시 개봉할 수 있다. 서비스는 운영 기간 동안 계속 메시지를 받는다.

## MVP 포함 (확정)

### 핵심 흐름
1. 트리 생성
2. 공유 링크 발급
3. 메시지 작성 (닉네임, 내용, 포켓몬 선택(랜덤 버튼, 확인 창, 이로치 2%), 볼)
4. 트리에 장식 표시 (닉네임만)
5. 12/25 개봉 (내용과 포켓몬 공개)
6. 받은 포켓몬 모아보기

### 추가 기능 (사용자 선택)
- **개봉 연출 애니메이션:** 선물상자가 열리며 포켓몬이 등장한다
- **트리 주인의 메시지 삭제:** 12/25 이전에는 장식(닉네임) 단위로만 판단해 삭제할 수 있다
- **악성 메시지 필터링:** 한국어 욕설·비속어 필터. 라이브러리 리서치가 필요하다 → [message-filtering.md](message-filtering.md)

### IP 대응 (ip-asset-policy.md에서 확정)
- 캐릭터 팩 분리 구조, 대체 팩, 비공식 고지, 연락 창구

## 출시 후 (12월 중 추가 검토)

- 트리 테마 선택
- QR 코드 공유
- 메시지 내보내기 (IP-4, 종료 전 필수)

## 제외

- 희귀도, 도감 완성 보상, 수집률, 업적·칭호 (game-rules.md 결정에 따름). 이로치는 2026-11-20에 MVP로 옮겼다 (#38)

## 일정 메모 (제안)

- 개봉 연출은 12/25에만 필요하다. 12/1 출시 직전에 일정이 빠듯하면 **12/1 이후 12/24 전까지 배포**하는 방법도 있다. 사용자 결정은 "MVP 포함"이므로, 밀리면 다시 확인한다.
