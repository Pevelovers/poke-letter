# 인증과 메시지 정책

> Source: Deep Interview, 2026-11-16

## Key Points (확정)

### 인증
- **트리 주인:** OAuth 로그인 — **카카오, 구글, 네이버** 세 가지를 지원한다.
- **메시지 작성자:** 로그인하지 않고 닉네임만 입력한다 (가정, 이전 단계 기준).

### 메시지
- **최대 길이:** 500자
- **임시 저장:** 작성 중인 내용을 **로컬스토리지에 자동 저장**한다. 브라우저가 갑자기 종료돼도 다시 열면 복구된다.
- **욕설 필터:** 감지된 **단어만 마스킹**(`***`)하고 메시지는 전송한다. 닉네임에도 같은 필터를 적용한다.

## 이 결정에서 나오는 요구사항 (제안)

| # | 요구사항 | 비고 |
|---|---|---|
| AU-1 | Spring Security OAuth2 Client로 3개 제공자를 연동한다. 구글은 기본 지원, 카카오·네이버는 제공자 설정을 직접 등록한다 | BE |
| AU-2 | 제공자별 앱 등록: 카카오 Developers, 네이버 Developers, Google Cloud Console | 출시 전 필수 |
| AU-3 | 계정 연동은 하지 않는다. 같은 사람이 카카오와 구글로 각각 로그인하면 별도 계정이 된다 (구현 단순화) | 확인 필요 |
| MS-1 | 자동 저장 키는 트리별로 분리하고(`draft:<treeId>`), 전송에 성공하면 삭제한다 | FE |
| MS-2 | 자동 저장은 입력을 멈춘 뒤 잠시 후(debounce) 저장한다. 로컬스토리지를 쓸 수 없는 환경(일부 시크릿 모드)에서도 작성은 가능해야 한다 | FE |
| MS-3 | 500자 제한은 FE(입력 제한)와 BE(검증) 모두에서 적용한다 | |
| MS-4 | 마스킹은 BE에서 **저장 전에** 처리한다. 원문은 저장하지 않는다 (개인정보·악성 내용 보관 최소화) | 제안, 확인 필요 |

## 일정 위험 (중요)

- **네이버 로그인:** 실제 서비스에 적용하려면 애플리케이션 **검수 요청**이 필요하다. '개발중' 상태에서는 등록한 테스트 아이디로만 로그인할 수 있다. **검수 기간과 테스터 수 제한은 웹 검색으로 확인하지 못했다.** 네이버 개발자센터에서 직접 확인해야 한다. 12/1까지 검수가 끝날지 불확실하다.
  - 출처: [카페24 가이드](https://support.cafe24.com/hc/ko/articles/8467208476569), [Logto 문서](https://docs.logto.io/integrations/naver)
- **카카오 로그인:** 사업자등록이 없는 개인 개발자도 '개인 개발자 비즈 앱'으로 전환할 수 있고, 전환하면 이메일을 받을 수 있다는 커뮤니티 안내가 있다. 전화번호·생년월일 등은 별도 심사가 필요하고 반려 사례가 많다. 회원번호만 받는 경우의 조건은 **공식 문서에서 확인이 필요하다.**
  - 출처: [Kakao DevTalk FAQ](https://devtalk.kakao.com/t/faq/133989), [Kakao DevTalk 이메일 동의항목](https://devtalk.kakao.com/t/account-email/151641), [Kakao DevTalk 심사 반려](https://devtalk.kakao.com/t/topic/140739)
- **제안:** 구글과 카카오를 먼저 출시에 맞추고, 네이버는 검수가 끝나는 대로 추가할 수 있도록 제공자를 설정 단위로 켜고 끄게 만든다.
