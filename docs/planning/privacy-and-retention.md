# 개인정보와 데이터 보관 정책

> Source: Deep Interview, 2026-11-16

## Key Points (확정)

- **OAuth 제공자에게서 받는 정보: 고유 ID만.** 이메일, 실명, 프로필 사진은 받지 않는다. 트리 이름은 사용자가 직접 입력한다.
- **1인 1트리.** 받은 포켓몬 모음도 트리 단위(곧 사용자 단위)로 관리한다.
- **서비스 종료: 2027년 1월 말.** 종료 후 데이터를 삭제한다.

## 일정 (계산)

| 날짜 | 내용 |
|---|---|
| 2026-12-01 (화) | 출시 |
| 2026-12-25 (금) | 일괄 개봉 |
| 2027-01-17 (일) 이전 | 종료 공지 (종료 2주 전, 제안) |
| 2027-01-17 이전 | 메시지 내보내기 기능 제공 (IP-4) |
| 2027-01-31 (일) | 서비스 종료 → 데이터 삭제 → 인프라 정리 |

## 수집하는 데이터 (현재 결정 기준)

| 데이터 | 대상 | 목적 | 비고 |
|---|---|---|---|
| OAuth 제공자 + 고유 ID | 트리 주인 | 로그인 | |
| 트리 이름 | 트리 주인 | 표시 | 사용자 입력 |
| 닉네임, 메시지(마스킹 후), 포켓몬 | 작성자 | 롤링페이퍼 | 로그인 없음. 메시지에 작성자가 개인정보를 직접 적을 수 있음 |
| IP 주소 등 요청 정보 | 작성자 | Rate Limit, 남용 방지 | **저장 방식 미정** (제안: 해시 처리 후 단기 보관, 또는 메모리에서만 사용) |

## 이 결정에서 나오는 요구사항 (제안)

| # | 요구사항 |
|---|---|
| PV-1 | 개인정보 처리방침 페이지 (수집 항목, 목적, 보관 기간 = 2027-01-31, 연락처) |
| PV-2 | 트리 주인의 탈퇴 = 트리·메시지 즉시 삭제 |
| PV-3 | 종료 공지 배너 (이메일을 받지 않으므로 사이트 안 공지만 가능) |
| PV-4 | 종료일에 DB 전체 삭제와 백업 삭제까지 포함한 정리 절차 |
| PV-5 | 마스킹 전 원문은 저장하지 않는다 (auth-and-messages.md MS-4, 제안) |

## 주의

- 고유 ID만 받아도 서비스는 개인정보를 처리한다. 작성자가 메시지에 개인정보를 적을 수 있고, IP 주소도 개인정보가 될 수 있다.
- 개인정보 보호법 등 **관련 법령에서 이 서비스에 어떤 의무가 생기는지는 확인하지 않았다.** 처리방침 작성 전에 확인이 필요하다.
