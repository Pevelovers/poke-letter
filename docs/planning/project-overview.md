# 프로젝트 개요 — 현황 분석

> Source: Deep Interview, 2026-11-16 (기획 프롬프트 분석)

## 확정 사항

- **주체:** GitHub Organization Pevelovers ("developers who LOVE Pokémon")
- **성격:** 비상업적 팬 프로젝트, 크리스마스 시즌 한정, 모바일 중심 웹
- **컨셉:** 크리스마스 트리 + 익명 롤링페이퍼 + 캐릭터 수집
- **참고 서비스:** 포케트리(PokéTree) — https://chimhaha.net/request_content/824276 (내용 미확인)
- **운영 원칙**
  1. 광고, 유료 결제·아이템·회원제, 후원·기부 없음
  2. 개발자 개인 비용으로 운영하며, 무료 티어와 저비용 인프라를 우선한다
  3. 실제 사용량에 맞춰 인프라를 선택한다 (과거 Cloud SQL 과잉 사양으로 비용 문제를 겪음)
  4. 시즌 종료 후 중단할 수 있도록 설계한다
  5. 비공식 팬 프로젝트임을 명시한다
- **IP 전제:** 비상업적이라는 이유만으로 포켓몬 IP 이용이 허락되지는 않는다
- **설계 방향:** 캐릭터 데이터·이미지 제공 방식을 핵심 로직에서 분리해 교체하기 쉽게 만든다
- **현재 개발 환경:** React + Spring Boot 모노레포 뼈대 완성 (PR #4). 단, 이번 서비스의 최종 스택으로 확정된 것은 아니다

## 대화에서 확인된 사실

- 2026-11-16 기준, 현재 개발 인원은 **1명** (사용자 본인). 다른 Org 멤버는 이 프로젝트에 참여하지 않는다.

## 일정 계산 (사실)

- 오늘: 2026-11-16 (월)
- 크리스마스: 2026-12-25 (금) → **39일 남음**
- 롤링페이퍼는 크리스마스 **전에** 메시지가 쌓여야 의미가 있으므로, 실제 출시 가능 기간은 39일보다 짧다

## 가정 (확인 필요)

- 사용자는 주로 한국어 사용자이며, 공유는 카카오톡·인스타그램 등 메신저/SNS 링크로 이루어진다
- 트래픽은 지인 공유 위주이며, 규모는 아직 추정 근거가 없다
