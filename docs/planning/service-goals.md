# 서비스 목표와 핵심 경험

> Source: Deep Interview, 2026-11-16

## Key Points (확정)

- **출시 목표일: 2026-12-01 (화) 경**
  - 개발 기간: 11/16 ~ 11/30, 약 15일
  - 메시지 수집 기간: 12/1 ~ 12/25, 약 24일
- **중심 경험: 롤링페이퍼**
  - 친구의 메시지를 받는 것이 주된 재미다
  - 캐릭터 수집은 메시지 개봉의 재미를 더하는 **보조 요소**다
  - 일정이 밀리면 수집 기능부터 단순화한다 (메시지 흐름은 지킨다)
- **인원: 1명** (사용자 본인). 개발과 디자인을 모두 직접 한다

## 이 결정에서 나오는 원칙 (제안, 확인 필요)

1. **MVP는 "트리 생성 → 공유 → 메시지 작성 → 장식 표시 → 개봉"이 완벽히 동작하는 것**을 기준으로 한다
2. 수집은 MVP에서 "개봉 시 캐릭터 1마리 + 간단한 도감 목록" 수준으로 시작하고, 희귀도·이로치·애니메이션은 출시 후로 미룬다
3. 디자인을 직접 해야 하므로 **직접 그려야 하는 그래픽의 양**이 일정의 가장 큰 위험이다
   - 트리 1종, 장식 소수 종류, 기본 UI는 shadcn/ui와 Tailwind로 해결하는 방향
   - 캐릭터 에셋을 어디서 가져올지가 일정에 큰 영향을 준다 → IP 결정과 직결
4. 출시 후 12/1~12/25 사이에 추가 기능을 배포할 수 있다 (운영 중 개선)
