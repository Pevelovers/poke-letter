## 서버 정보 (지인 관리 서버, 11/22까지 받기)

기존 서버는 지인이 관리하고 있어 아직 정보가 없다. 도메인 등록, OAuth 앱 등록, 로컬 개발에는 필요 없지만, 배포(11/28~29) 직전에 서버를 쓸 수 없다고 알게 되면 대안을 준비할 시간이 없다. 그래서 **11/22(일)까지** 받는다. 받지 못하거나 쓸 수 없으면 그때 대안 서버(상시 실행되는 무료 VM 등)를 정한다.

### 꼭 필요 (이게 없으면 배포 불가)

- [ ] **사용 동의:** 2026-12-01 ~ 2027-01-31 운영, 종료 후 삭제. 데이터 전송 요금이 지인 계정에 나가는 점
- [ ] **접근 방법:** SSH 접속 권한을 받을 수 있는지, Docker(+Compose)를 쓸 수 있는지
- [ ] **장애 대응 권한:** 재시작·롤백(POL-OPS-05)을 직접 할 수 있는지. 권한이 없으면 12/25 0시 대응을 지인이 맡아야 한다
- [ ] **고정 IP(Elastic IP) 여부와 공인 IP 주소** → DuckDNS에 등록
- [ ] **여유 메모리와 디스크** (`free -h`, `df -h`). JVM 힙과 백업 보관 공간을 정한다
- [ ] **리버스 프록시:** 80/443을 쓰는 프록시 종류(Nginx, Caddy 등), 우리 도메인(`pokeletter.duckdns.org`)을 추가하고 Let's Encrypt 인증서를 받을 수 있는지, 설정을 누가 바꾸는지
- [ ] **CPU·인스턴스 종류** (`lscpu` 또는 EC2 인스턴스 유형, `grep -o avx512vbmi /proc/cpuinfo | head -1`). x86-64 + AVX-512 VBMI면 **CVE-2026-114938** 공격 조건을 만족한다 ([infra.md](infra.md#보안-cve-2026-114938-java4shell))
