# 남은 질문

> Source: Deep Interview, 2026-11-16

## 바로 정해야 함 (11/17까지, 외부 신청에 필요)

- [ ] **서비스 이름** — 상표("포켓몬", "Pokémon")가 들어가지 않는 이름을 권장
- [ ] **도메인** — OAuth 콜백 URL과 공유 링크에 필요
- [ ] **권리자 연락 창구 이메일** (IP-5)

## 구현 전에 정해야 함

- [ ] 포켓몬 이미지 제공 방식: 외부 스프라이트 URL을 직접 쓸지, 자체 호스팅할지. 직접 쓴다면 해당 서비스의 이용 정책을 확인해야 한다
- [ ] 대체 캐릭터 팩의 형태 (범용 오너먼트 몇 종으로 할지)
- [ ] 트리·장식 디자인 방향 (픽셀 아트 여부, 장식 종류 수)
- [ ] 장식이 많아질 때 표시 방식 (페이지 넘김, 확대, 개수 제한)
- [ ] 닉네임 최대 길이 (10자 안팎 제안)
- [ ] 작성자 남용 방지: Rate Limit 기준, IP 주소 저장 여부와 방식
- [ ] 마스킹 전 원문 저장 여부 (원문을 저장하지 않는 쪽을 제안)
- [ ] 탈퇴 기능을 MVP에 넣을지
- [ ] 트리 주인이 자기 트리에 메시지를 쓸 수 있는지
- [ ] 메시지 내보내기 형식 (텍스트, 이미지 등)

## 확인 필요 (조사 또는 외부 확인)

- [ ] 네이버 로그인 검수 기간과 '개발중' 상태의 테스터 제한 (네이버 개발자센터)
- [ ] 카카오 로그인에서 회원번호만 받을 때의 조건 (카카오 공식 문서)
- [ ] Supabase 무료 티어 한도를 공식 가격 페이지에서 확인하고, 일시 중지를 막으려면 어떤 요청이 "활동"으로 인정되는지 확인
- [ ] EC2의 실제 여유 메모리(`free -h`)와 이미 있는 리버스 프록시
- [ ] AWS 데이터 전송 요금 체계 (FE 정적 파일 제공 시)
- [ ] 개인정보 보호법 등 이 서비스에 적용되는 법령상 의무
- [ ] PokéAPI 데이터 이용 정책 (캐싱 요청 등)
