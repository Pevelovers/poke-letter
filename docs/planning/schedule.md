# 일정과 작업 방식

> Source: Deep Interview, 2026-11-16

## Key Points (확정)

- **개발 시간:** 평일 저녁(2~3시간) + 주말
- **FE 배포:** 같은 EC2 서버에서 정적 파일로 제공 (추천안 채택)
- **일정이 밀리면 12/1 이후로 미룰 항목** (12/25 전에만 배포하면 된다)
  1. 개봉 연출 애니메이션
  2. 받은 포켓몬 모아보기
  3. 네이버 로그인
  4. 일일 백업 자동화 (그전까지는 수동 백업)

## 가용 시간 (계산)

| 기간 | 평일 | 주말 |
|---|---|---|
| 11/16(월) ~ 11/30(월) | 11일 × 2~3시간 = **약 22~33시간** | 4일 (11/21–22, 11/28–29), 시간 미정 |

- 주말에 쓸 수 있는 시간은 아직 모른다. 그래서 총 개발 시간은 추정하지 않았다.

## 위험

- **트래픽 폭증:** 비슷한 서비스가 출시 5일 만에 최대 동시 접속 약 117만을 기록했다. 지인 서버와 무료 DB로는 감당할 수 없을 수 있어 12/15에 이전을 판단한다 ([트래픽 대비 계획](traffic-plan.md)).
- **범위 대비 시간이 빠듯하다.** OAuth 두 종, 포켓몬 선택기, 필터, 12/25 공개 제어, 배포를 평일 저녁과 주말 두 번 안에 끝내야 한다. 11/22(일)에 BE 진행 상황을 보고 범위를 다시 조정하기를 권한다.
- **외부 의존 작업:** 도메인과 OAuth 앱 등록은 11/18에 끝났다. 네이버 검수는 실제 접속되는 서비스에서 로그인 흐름을 확인하므로 배포 후에 신청한다. 검수 기간은 통제할 수 없지만, 네이버 로그인은 원래 출시 후에 켜기로 해서 일정 영향은 없다.
- **서버 정보:** 배포할 서버는 지인이 관리해 정보가 없다. 11/17에 요청하고 11/22(일)까지 받는다. 이때 BE 진행 상황 점검과 함께 서버를 쓸 수 있는지 판단하고, 안 되면 대안 서버를 정한다 ([남은 질문](_open-questions.md#서버-정보-지인-관리-서버-1122까지-받기)).
- **디자인:** 트리와 장식 그래픽을 직접 만들어야 한다. 위 일정에는 디자인 시간이 따로 잡혀 있지 않다.
