# 디자인 방향

> 버전 1.1 · 2026-11-20 · 상태: **확정** (세부 디자인은 작업하며 갱신)
> 관련: [기능 정의서](features.md) F-TRE-10, 11, F-CHR-06 · [정책 정의서](policies.md) POL-CHR-06, 10, POL-IP-02

## 1. 스타일: 도트 + 일반 UI

| 대상 | 스타일 | 이유 |
|---|---|---|
| 트리, 배경, 장식 볼, 포켓몬 | **도트(픽셀 아트)** | PokéAPI 스프라이트(포켓몬 96×96, 볼 30×30)가 도트라 그림체가 맞는다. 혼자 만들기에 작업량이 적다 |
| 버튼, 입력창, 시트, 대화상자 | **일반 UI** (shadcn 컴포넌트 + 크리스마스 색) | 모바일에서 누르기 쉽고 접근성이 좋다. 전부 도트로 만들면 작업량이 크다 |

### 도트 렌더링 규칙

- 이미지는 **정수 배율**(2×, 3×, 4×)로만 키운다. 소수 배율은 픽셀이 뭉개진다
- `image-rendering: pixelated`를 적용한다
- 같은 화면 안에서는 배율을 하나로 맞춘다 (포켓몬 2×와 볼 3×가 섞이면 픽셀 크기가 달라 보인다)

### 글꼴

- [제안] 제목에만 한글 도트 글꼴(예: Galmuri, SIL OFL)을 쓴다. 도입할 때 라이선스 표기와 함께 확인한다
- **메시지 본문은 일반 글꼴**로 쓴다. 500자를 도트 글꼴로 읽기는 어렵다

## 2. 트리 화면 배경: 야외, 낮·밤 전환

- 트리가 서 있는 **야외** 장면 (눈 덮인 마당, 하늘)
- **서울 일출·일몰 시각** 기준으로 낮과 밤이 바뀐다 (F-TRE-10)
  - 사용자 위치를 쓰지 않는다. 위치 권한이 필요 없고 개인정보를 받지 않는다 (POL-PRV-01)
  - 서비스 기간(12/1~1/31)의 날짜별 서울 일출·일몰 시각 표를 FE에 둔다. 계산 라이브러리를 쓰지 않는다
  - 표의 값은 만들 때 천문 자료로 확인해 출처를 적는다
  - 시각 판단은 사용자 기기 시각을 한국 시간(KST)으로 바꿔서 한다. 해외 사용자도 서울의 낮·밤을 본다
- 12/25 00:00 개봉은 밤 배경에서 열린다

| 단계 | 시간대 | 우선순위 |
|---|---|---|
| 낮 | 일출 ~ 일몰 | P0 |
| 밤 | 일몰 ~ 다음 날 일출 | P0 |
| 노을 | 일몰 전후 30분 | P1 (F-TRE-11) |
| 새벽 | 일출 전후 30분 | P1 (F-TRE-11) |

## 3. 장식: 볼

- 트리 장식은 **볼**이다. 작성자가 PokéAPI 볼 아이템 **38종 전체** 중에서 고른다 (POL-CHR-10, F-CHR-06)
- 작성 폼을 열면 몬스터볼이 미리 선택되어 있다
- 이미지는 PokéAPI 아이템 스프라이트 URL을 그대로 쓴다. 직접 그리지 않는다 (POL-IP-03)
- 이름이 겹치는 히스이 볼 4종만 `몬스터볼(히스이)`처럼 표기한다

| 분류 | 볼 |
|---|---|
| 일반 (8) | 몬스터볼, 슈퍼볼, 하이퍼볼, 마스터볼, 사파리볼, 파크볼, 컴퍼티션볼, 울트라볼 |
| 특수 (12) | 네트볼, 다이브볼, 네스트볼, 리피트볼, 타이머볼, 럭셔리볼, 프리미어볼, 다크볼, 힐볼, 퀵볼, 프레셔스볼, 드림볼 |
| 구 볼 (7) | 루어볼, 레벨볼, 문볼, 헤비볼, 스피드볼, 프렌드볼, 러브러브볼 |
| 히스이 (11) | 스트레인지볼, 몬스터볼(히스이), 슈퍼볼(히스이), 하이퍼볼(히스이), 헤비볼(히스이), 메가톤볼, 기가톤볼, 페더볼, 윙볼, 제트볼, 오리진볼 |

## 3-1. 이로치와 공개 후 트리 (2026-11-20, #38)

- 이로치 이미지는 PokéAPI 이로치 스프라이트(`front_shiny`) URL을 그대로 쓴다. 직접 그리지 않는다 (POL-IP-03)
- 선택 확인 창: 화면 가운데 창, 포켓몬 스프라이트 2×, 이름, "이 아이를 맡길까?", 예·아니오. 이로치면 반짝임 효과를 함께 보여 준다
- 공개 전 트리: 이로치가 든 볼에 반짝임 표시
- 공개 후 트리: 볼 대신 포켓몬 스프라이트를 단다. [결정 필요] 포켓몬 스프라이트(96×96)는 볼(30×30)보다 커서 같은 배율로 10개를 달기 어렵다. 우선 1×로 달고 트리 배율을 디자인할 때 다시 정한다

## 4. 이름 표기

- 포켓몬 리전폼도 **원래 이름 그대로** 보여 준다 (알로라 라이츄 → 라이츄). 긴 이름은 UI를 해친다 (POL-CHR-06)
- 볼은 이름이 겹치는 히스이 볼만 괄호를 붙인다. 괄호는 앞말에 붙여 쓴다 (`몬스터볼(히스이)`)

## 5. 대체 팩 (권리자 요청 시)

포켓몬과 볼은 모두 공식 디자인이다. 대체 팩으로 바꾸면 **둘 다** 바꾼다 (POL-IP-02).

| 대상 | 포켓몬 팩 | 대체 팩 |
|---|---|---|
| 캐릭터 | 포켓몬 스프라이트 | 오너먼트 N종 (직접 그린 도트) |
| 장식 볼 | 볼 스프라이트 38종 | 일반 크리스마스 볼 M종 (직접 그린 도트, 색만 다르게) |

- 대체 팩 에셋도 같은 도트 스타일로 그린다
- N, M은 디자인할 때 정한다
