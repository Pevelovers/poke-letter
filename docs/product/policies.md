> 버전 1.1 · 2026-11-20 · 상태: **확정** (구현 중 바뀌는 내용은 새 버전으로 기록)
> 2026-11-20 개정 (#38): 숨김 랜덤을 없애고 선택기의 랜덤 선택 버튼으로 바꿈, 선택 확인 창, 이로치 2%, 공개 전 이로치 볼 반짝임, 공개 후 트리에 포켓몬 표시

## 공통

- **기준 시간대:** `Asia/Seoul` (KST). 서버와 DB는 UTC로 저장하고, 비교·표시할 때 KST로 바꾼다.
- **문자 수 기준:** 사용자가 보는 글자 수(유니코드 코드 포인트)로 센다. 앞뒤 공백은 제거한 뒤 센다.

## 계정 (ACC)

| ID | 정책 |
|---|---|
| POL-ACC-01 | 트리 주인은 카카오·구글·네이버 OAuth로만 로그인한다. 자체 회원가입이나 비밀번호는 없다. |
| POL-ACC-02 | 로그인 제공자는 서버 설정으로 켜고 끌 수 있다. 꺼진 제공자의 버튼은 화면에 나오지 않는다. 출시 시점 기본값: 구글·카카오 켜짐, 네이버는 검수 후 켬. |
| POL-ACC-03 | 로그인 상태는 서버 세션 쿠키로 유지한다. 유지 기간 30일. 서버를 재배포하면 다시 로그인해야 할 수 있다. |
| POL-ACC-04 | 계정은 (제공자, 제공자 고유 ID) 쌍으로 구분한다. 같은 사람이 다른 제공자로 로그인하면 별도 계정이 된다. 계정 연동은 하지 않는다. |

## 트리 (TRE)

| ID | 정책 |
|---|---|
| POL-TRE-01 | 계정당 트리는 1개만 만들 수 있다. |
| POL-TRE-02 | 트리 이름은 1~20자이며 필수다. 욕설·음담패설이 있으면 등록할 수 없다(POL-FLT-06). 만든 뒤 이름은 바꿀 수 없다. |
| POL-TRE-03 | 트리 공유 ID는 추측하기 어려운 무작위 문자열이다 (영숫자 10자). 내부 DB ID는 URL에 노출하지 않는다. |
| POL-TRE-04 | 장식은 오래된 순으로 배치한다. 한 화면에 10개씩 보여 주고 넘겨 본다. |
| POL-TRE-05 | 트리 보기(공유 링크)는 로그인 없이 누구나 볼 수 있다. 보이는 정보는 트리 이름, 장식 개수, 작성자 닉네임, 작성 시각뿐이다. |

## 메시지 (MSG)

| ID | 정책 |
|---|---|
| POL-MSG-01 | 메시지 내용은 1~500자이며 필수다. 줄바꿈은 허용한다. |
| POL-MSG-02 | 닉네임은 1~10자이며 필수다. 욕설 필터를 적용한다. |
| POL-MSG-03 | 작성자는 로그인하지 않는다. 같은 사람이 같은 트리에 여러 번 쓸 수 있다 (Rate Limit 범위 안에서). |
| POL-MSG-04 | 보낸 메시지는 작성자가 수정하거나 삭제할 수 없다. (작성자를 식별할 수단이 없음) |
| POL-MSG-05 | 작성 중인 내용은 작성자 기기의 로컬스토리지에만 임시 저장한다. 서버에는 전송 전까지 아무것도 보내지 않는다. 로컬스토리지를 쓸 수 없는 환경에서도 작성은 가능하다. 임시 저장은 **전송에 성공했을 때만** 지운다. 전송이 실패하면(Rate Limit `429`, 네트워크 오류 등) 내용을 그대로 남겨 두고, 다시 열거나 잠시 뒤 재시도할 때 불러온다. |
| POL-MSG-06 | 트리 주인은 언제든 메시지를 삭제할 수 있다. 공개 전에는 닉네임만 보고 판단한다. 삭제는 즉시 영구 삭제이며 복구할 수 없다. |
| POL-MSG-07 | 메시지는 일반 텍스트로만 저장하고 표시한다. HTML과 마크다운은 해석하지 않는다. 제어 문자는 저장 전에 제거한다. |

## 공개 시점 (RVL)

| ID | 정책 |
|---|---|
| POL-RVL-01 | **공개 시각은 2026-12-25 00:00 KST**이며 서버 설정값이다. 공개 시각 전에는 메시지 내용과 포켓몬을 **API 응답 어디에도 포함하지 않는다.** 화면에서 가리는 것만으로는 안 된다. 예외: 장식에 이로치가 들었는지(`shiny`)는 공개 전에도 내려준다 (POL-CHR-12). 어떤 포켓몬인지는 알 수 없다. |
| POL-RVL-02 | 공개 시각 이후에는 트리 주인이 모든 메시지를 볼 수 있다. 공개 시각 이후에 도착한 메시지는 도착 즉시 볼 수 있다. (규칙: `현재 시각 ≥ 공개 시각`이면 공개) |
| POL-RVL-03 | **메시지 내용은 트리 주인만 볼 수 있다.** 방문자와 작성자는 공개 후에도 내용을 볼 수 없다. **포켓몬은 공개 후 트리 화면에서 누구나 본다**: 공개 후 트리에는 볼 대신 포켓몬(이로치 포함)이 달린다 (2026-11-20 변경, 이전: 포켓몬도 주인만). |
| POL-RVL-04 | 공개 여부는 서버 시각으로만 판단한다. 클라이언트 시각은 남은 시간 표시에만 쓴다. |

## 캐릭터 (CHR)

| ID | 정책 |
|---|---|
| POL-CHR-01 | 선택할 수 있는 포켓몬은 전체 포켓몬의 기본 폼과 리전폼(알로라, 가라르, 히스이, 팔데아)이다. 메가진화, 거다이맥스 등 나머지 폼은 제외한다. 이로치(색이 다른 모습)는 고를 수 없고 확률로 당첨된다 (POL-CHR-12). PokéAPI에서 이로치는 폼이 아니라 같은 포켓몬의 다른 이미지(`sprites.front_shiny`)이므로, 시드할 때 기본 이미지(`front_default`)와 이로치 이미지(`front_shiny`)를 함께 받는다. 이로치 이미지가 없는 폼은 기본 이미지를 쓴다. |
| POL-CHR-02 | 메시지 하나에 포켓몬 하나가 반드시 붙는다. |
| POL-CHR-03 | **랜덤 선택:** 포켓몬 선택 화면의 "랜덤" 버튼을 누르면 FE가 선택 가능한 전체 포켓몬 중 한 마리를 균등 확률로 고르고 확인 창을 띄운다 (POL-CHR-11). 난수는 `crypto.getRandomValues`와 거절 샘플링으로 뽑아 모듈러 편향이 없게 한다. 이 트리가 받은 포켓몬을 빼지 않는다 (2026-11-20 변경, 이전: 서버가 "전체 − 이 트리가 받은 포켓몬"에서 고름). |
| POL-CHR-04 | 랜덤 버튼으로 고른 포켓몬도 작성자가 확인 창에서 보고 고른 것이므로 **직접 고른 것과 같게 기록한다.** 작성자도 결과를 모르는 "숨김 랜덤(랜덤으로 보내기)"은 2026-11-20에 없앴다. |
| POL-CHR-05 | 직접 고를 때는 중복을 허용한다. 받은 포켓몬 모아보기에서는 같은 포켓몬을 하나로 묶고 받은 횟수를 표시한다. 전체 도감, 수집률, 빈칸은 보여 주지 않는다. |
| POL-CHR-06 | 포켓몬 표기는 한국어 이름을 쓴다. **리전폼도 화면에는 원래 이름 그대로** 보여 준다 (알로라 라이츄 → "라이츄", 팔데아 켄타로스 3종 → "켄타로스"). 긴 이름은 UI를 해치므로 지역명을 붙이지 않는다. 구분은 코드(`form`)와 이미지로 한다. |
| POL-CHR-07 | 선택기의 세대는 **폼이 처음 나온 세대**로 한다 (예: 라이츄 1세대, 알로라 라이츄 7세대). 종의 세대가 아니라 PokéAPI `pokemon-form`의 `version_group`이 속한 세대를 쓴다. 타입은 폼마다 따로 쓴다 (알로라 라이츄 = 전기·에스퍼). |
| POL-CHR-08 | 선택기 필터: 세대(1~9)와 타입(18종)을 여러 개 고를 수 있다. 같은 필터 안에서는 OR, 세대·타입·이름 검색끼리는 AND로 묶는다. 예: 1세대 + (불꽃 또는 비행) → 파이리, 리자몽, 피존 등. 복합 타입은 둘 중 하나만 맞아도 포함된다. |
| POL-CHR-11 | **선택 확인 창:** 선택기에서 포켓몬을 누르거나 랜덤을 누르면 화면 가운데에 확인 창을 띄운다. 스프라이트(이로치면 이로치 이미지)와 이름, "이 아이를 맡길까?", "예"·"아니오"를 보여 준다. "예"를 눌러야 선택되고, "아니오"면 선택기로 돌아간다. |
| POL-CHR-12 | **이로치:** 확인 창을 띄울 때마다 **2% 확률**(1/50)로 이로치가 당첨된다. FE가 `crypto.getRandomValues`와 거절 샘플링으로 뽑아 모듈러 편향이 없게 한다. "아니오" 후 다시 고르면 새로 뽑는다. 결과는 메시지 전송 때 `shiny`로 보내 저장한다. 요청을 조작하면 이로치를 고를 수 있지만 꾸미기 요소라 감수한다. 공개 전에는 이로치가 든 장식 볼에 반짝임을 표시하고, 공개 후에는 이로치 스프라이트로 보여 준다. 받은 포켓몬 모아보기에서는 이로치를 따로 묶는다. |
| POL-CHR-10 | **장식 볼:** 작성자는 메시지마다 볼 하나를 고른다. 후보는 PokéAPI의 볼 아이템 전체(38종)다. 작성 폼을 열면 몬스터볼이 미리 선택되어 있다. 볼은 12/25 전에 트리에 보이고, 공개 후에는 포켓몬으로 바뀐다 (POL-RVL-03). 일반 볼과 이름이 겹치는 히스이 볼 4종만 `몬스터볼(히스이)`처럼 괄호를 붙여 쓴다 (괄호는 앞말에 붙여 쓴다). |
| POL-CHR-09 | 선택기 이름 검색: 한국어 이름의 **어느 위치든 부분 일치**하면 나온다. 공백은 무시한다. 입력에 초성(ㄱ~ㅎ)이 있으면 그 자리는 이름 글자의 초성과 비교하고, 완성된 글자는 그대로 비교한다. 초성과 완성 글자를 섞어 쓸 수 있다. 예: `ㅍㅋㅊ`·`피ㅋ츄` → 피카츄, `ㄹㅇㅊ` → 라이츄·알로라 라이츄, `이브` → 이브이. 숫자만 입력하면 도감 번호로 찾는다. 쌍자음은 따로 구분한다(`ㄱ`으로 `꼬부기`가 나오지 않음). |

## 욕설 필터 (FLT)

| ID | 정책 |
|---|---|
| POL-FLT-01 | 필터는 서버에서 저장 전에 적용한다. 대상은 메시지 내용, 닉네임, 트리 이름이다. 메시지 내용과 닉네임은 마스킹(POL-FLT-02)하고, 트리 이름은 거절(POL-FLT-06)한다. |
| POL-FLT-02 | (메시지 내용, 닉네임) 최종 저장할 때 감지된 단어는 같은 길이의 `*`로 바꾼다. 전송 전 1회 거부(POL-FLT-07)를 거친 뒤에는 전송을 막지 않는다. |
| POL-FLT-03 | 마스킹 전 원문은 저장하지 않는다. |
| POL-FLT-04 | 감지할 때는 공백·특수문자·숫자 끼워 넣기 같은 우회 표기를 정규화한 뒤 비교한다. 마스킹은 원문 위치에 적용한다. |
| POL-FLT-05 | 사전은 출처와 라이선스를 기록하고 저장소에 둔다 (예: badwords-ko MIT, LDNOOBW `ko` CC-BY-4.0 출처 표기). 욕설뿐 아니라 성적인 표현(음담패설)도 사전에 포함한다. |
| POL-FLT-07 | (메시지 내용, 닉네임) **입력 중에는 검사하지 않는다.** 보내기를 눌렀을 때 서버가 검사하고, 처음 감지되면 저장하지 않고 1회 거부한다. 고치지 않은 채 다시 보내면 FE가 계속 막는다. 내용을 고친 뒤 보내면 무조건 저장하고, 여전히 감지되면 POL-FLT-02대로 마스킹한다. 거부 상태는 FE 메모리에만 두며 새로고침하면 초기화된다. 거부 응답에도 감지된 단어는 넣지 않고 어느 칸(닉네임/내용)인지만 알려 준다. 거부된 요청도 Rate Limit 횟수에 포함한다 (사전 내용을 떠보는 반복 요청 방지). |
| POL-FLT-06 | 트리 이름에 사전의 단어가 감지되면 마스킹하지 않고 등록을 거절한다. 트리 이름은 공유 링크 미리보기와 트리 화면에 크게 보이고 바꿀 수 없기 때문이다. 어떤 단어가 감지됐는지는 응답에 넣지 않는다. 사전은 단어 단위라 문장으로 돌려 말한 표현은 걸러내지 못할 수 있다. |

## 남용 방지 (ABU)

| ID | 정책 |
|---|---|
| POL-ABU-01 | 메시지 작성은 요청 IP 기준으로 횟수를 제한한다. 1분에 5회, 1시간에 30회. 넘으면 `429`와 안내 문구를 돌려준다. 통신사 망이나 같은 와이파이처럼 여러 사람이 IP 하나를 함께 쓸 수 있으므로 너무 낮게 잡지 않는다. 차단된 작성자의 내용은 POL-MSG-05에 따라 보존한다. |
| POL-ABU-02 | IP 주소는 Rate Limit을 위해 서버 메모리에서만 쓰고 DB에 저장하지 않는다. 서버를 재시작하면 카운터가 초기화된다. |
| POL-ABU-03 | 트리 하나가 받을 수 있는 메시지는 최대 200개다. 넘으면 작성을 막는다. (DB 용량과 화면 표시 보호) |
| POL-ABU-04 | 로그인한 사용자의 상태 변경 요청(트리 생성, 메시지 삭제, 탈퇴)은 CSRF 토큰을 검증한다. |

## 개인정보 (PRV)

| ID | 정책 |
|---|---|
| POL-PRV-01 | OAuth 제공자에게서는 고유 ID만 받는다. 이메일, 이름, 프로필 사진, 전화번호는 요청하지 않는다. |
| POL-PRV-02 | 수집 항목: (트리 주인) 제공자, 제공자 고유 ID, 트리 이름 / (작성자) 닉네임, 메시지, 선택한 포켓몬. 작성 시각은 모두 기록한다. |
| POL-PRV-03 | 탈퇴하면 계정, 트리, 그 트리의 모든 메시지를 즉시 영구 삭제한다. |
| POL-PRV-04 | 모든 데이터의 보관 기한은 2027-01-31이다. 종료 시 DB와 백업을 모두 삭제한다. |
| POL-PRV-05 | 서버 로그에 메시지 내용과 제공자 고유 ID를 남기지 않는다. |
| POL-PRV-06 | 개인정보 처리방침에 위 내용과 연락처를 적는다. 적용 법령상 의무는 처리방침을 쓰기 전에 확인한다. |

## IP·에셋 (IP)

| ID | 정책 |
|---|---|
| POL-IP-01 | 모든 화면에서 비공식 팬 프로젝트 고지에 접근할 수 있다. 문구: 비공식 팬 프로젝트이며 공식 서비스와 관련이 없다 / 포켓몬 관련 명칭과 이미지의 권리는 각 권리자에게 있다 / 비상업적으로 운영한다 / 연락처. 연락처는 서비스 전용 메일 주소 `pokeletter.contact@gmail.com`다. 주소는 FE 문구에 직접 쓰지 않고 설정 값 한 곳에서 읽어, 바꿀 때 한 곳만 고치게 한다. |
| POL-IP-02 | 캐릭터 정보는 "캐릭터 팩"으로 분리한다. 활성 팩은 서버 설정 하나로 바꾼다. 대체 팩으로 바꾸면 기존 메시지의 포켓몬은 정해진 규칙(번호 기준)에 따라 대체 오너먼트로 표시되고, 메시지 내용은 그대로 남는다. **장식 볼도 공식 디자인이므로 함께 일반 크리스마스 볼로 바꾼다** (볼 번호 기준 대응, ERD 참고). |
| POL-IP-03 | 포켓몬 이미지 파일은 저장소에 커밋하지 않는다. 이미지는 외부 스프라이트 URL을 그대로 쓰고 직접 호스팅하지 않는다. 불러오지 못하면 기본 오너먼트를 보여 준다. |
| POL-IP-04 | 포켓몬 목록(번호, 한국어 이름, 이미지 URL)은 저장소에 데이터 파일로 커밋하지 않는다. 배포할 때 시드 스크립트가 PokéAPI에서 받아 DB에 넣는다. 런타임에는 PokéAPI를 호출하지 않는다. |
| POL-IP-05 | 권리자의 요청을 받으면 (1) 즉시 대체 팩으로 전환하고 (2) 요청 내용을 기록하며 (3) 필요하면 종료 절차(POL-END)를 앞당긴다. |
